# Account Management WebSocket

Authentication and account management

[Markup Statistics Auth required

Retrieve aggregated markup and trading statistics for your registered applications over a date range. `markup_statistics`](/docs/account/markup-statistics/)

[Balance Auth required

Get the account's balance `balance`](/docs/account/balance/)

[Portfolio Auth required

Get a list of all open positions for the authorized account. `portfolio`](/docs/account/portfolio/)

[Profit Table Auth required

Retrieve a summary of account profit/loss. `profit_table`](/docs/account/profit-table/)

[Statement Auth required

Retrieve account statement. `statement`](/docs/account/statement/)

[Transaction Auth required

Subscribe to transaction notifications. `transaction`](/docs/account/transaction/)
